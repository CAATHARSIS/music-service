*Бэкенд музыкального сервиса с генерацией плейлистов на основе пользовательских правил*

| Сервис               | Порт  | Назначение                                              |
| -------------------- | ----- | ------------------------------------------------------- |
| **API Gateway**      | 8080  | Единая точка входа, преобразует HTTP в gRPC             |
| **Auth Service**     | 50051 | Аутентификация                                          |
| **File Service**     | 50052 | Загрузка и выдача файлов, работа с объектным хранилищем |
| **Catalog Service**  | 50053 | Управление музыкальным каталогом и поиск                |
| **Playlist Service** | 50054 | Управление плейлистами                                  |
| **Rule Engine**      | 50055 | Генерация плейлистов по правилам                        |

Для запуска необходим Docker и Docker Compose и .env файл (примерное содержание конфигурационного файла лежит в .env.example)

Сервис разворачивается с помощью команды `docker compose up -d --build` из корня проекта
